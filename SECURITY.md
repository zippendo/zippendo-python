# Security policy

## Reporting a vulnerability

Please report a security issue privately by email to **support@zippendo.com** with "Security" in the
subject, not in a public issue. Include the SDK, its version and the steps to reproduce. This covers
this SDK and the Zippendo API it calls.

## Supported versions

Fixes ship in a new release; earlier versions are not patched. Every Zippendo SDK is released under
the same version number, so a fix reaches all of them at once.

## Where this code comes from

This repository is generated from the Zippendo public API specification
(<https://api.zippendo.com/public/json>) with [OpenAPI Generator](https://openapi-generator.tech) and
published by Zippendo's release pipeline. A change made here directly is replaced by the next release,
so report problems in an issue or by email rather than a pull request.
